# Control de Lotes Ganaderos

Aplicación frontend inicial desarrollada con **Vite** y **TypeScript** (Vanilla) como base para las preentregas y el proyecto final de la diplomatura.

## Temática y descripción

El proyecto permite visualizar un conjunto inicial de lotes ganaderos, calcular valores estimados según cantidad de cabezas, peso promedio y valor por kilogramo, y simular incrementos de peso promedio desde la interfaz para observar cómo se actualizan los datos en pantalla.

## Tecnologías utilizadas

- **TypeScript** (con modo estricto habilitado)
- **Vite**
- **HTML5** y **CSS3**
